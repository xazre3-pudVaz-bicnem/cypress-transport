## JobPosting を求人検索向けに拡充（10プロパティ → 20）
description に埋め込むだけだった条件を、Google が絞り込みに使う個別プロパティにも出す。
  workHours / qualifications / skills / experienceRequirements /
  occupationalCategory（O*NET-SOC 53-3033）/ industry / employmentUnit /
  incentiveCompensation / experienceInPlaceOfEducation
「未経験可」は monthsOfExperience: 0 として表現し、未経験の検索条件に拾われるようにした。
出来高部分は baseSalary（最低保証）に混ぜず incentiveCompensation に分離している。
hiringOrganization に住所と @id を追加。

## エンティティグラフの統合
Organization に法人番号（identifier）、対応エリア12件（areaServed）、
代表者（employee: Person）、採用窓口（contactPoint + 受付時間）、knowsAbout を追加。
記事の author / publisher を個別ノードから Organization の @id 参照に変更し、
「サイト運営者」と「記事の書き手」が別実体に見える状態を解消した。

## AI検索対策
- robots.ts に Google-Extended / GPTBot / OAI-SearchBot / ClaudeBot /
  PerplexityBot / Applebot-Extended / CCBot など11のAIクローラーを明示許可
- /llms.txt を追加。会社情報・確定条件・求人・記事一覧を data/ から自動生成する。
  AIが古い数字や他社条件と混同しないよう「推測で補完しないでください」と明記し、
  写真がイメージカットである旨・記事の一般論と自社条件が別である旨も記載した

## 内部リンク（クロール計測で判明した弱点）
被リンクが1〜2本しかなかった /recruit/benefits /recruit/flow /recruit/faq
/recruit/area /company/story をフッターの2グループ構成で全ページから到達可能にした。
記事下部に求人への導線ブロックを追加。
結果、noindex記事1件を除き全ページの被リンクが27本になった。

## 最重要キーワードページの強化
/recruit/jobs が600字と薄かったため、求人ブロック・共通条件表・エリア・
よくある質問・関連記事を追加して2321字に。「軽貨物 求人」「葛飾区 軽貨物 求人」の受け皿にする。

地図で確認できる事実のみで、所要時間は拠点確定まで書かない方針を明記した。
